## Change and contracts

Use frozen stage-entry root height/RPY and world wheel anchors. Compute the
incenter of the three nonselected supports, then interpolate measured COM toward
it only enough to request .03m planar margin. Translate the body target accordingly,
but reject requests exceeding .06m from stage entry. Root target rate <=.02m/s;
each joint target rate <=.5rad/s. Rates and bound are initial unvalidated parameters.
M1 analytical IK plus its FK residual/physical joint limits validate all four legs.
No measured-joint drift is integrated into the anchor/reference.

Return previous command with valid=false and reason code for invalid data,
degenerate/inadequate support triangle, out-of-bound displacement, IK/limit error,
or joint slew. Caller must handle recovery; returning previous command does not
prove it is safe under lost support. This function does not command wheel speeds,
check collision, move the simulator, or authorize lifting. PREPARE gate and full
coordinator still own contacts, identity, stage timeouts and recovery.
