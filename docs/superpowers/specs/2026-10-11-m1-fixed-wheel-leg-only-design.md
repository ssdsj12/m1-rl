# M1 固定轮速、12维腿部PPO设计

日期：2026-10-11（UTC）。状态：用户已确认书面方案和0.30m/s，补充“速度跟踪不要太准也行”；进入实施，尚未部署。

## 1. 已确认目标及备选裁定

用户明确：轮子持续按固定前进轮速驱动，PPO只控制12个腿关节，学习抬轮、三轮支撑、落轮；
小障碍跨越，大障碍绕行，不引入轮速差转向。选择严格12维方案。
排除“固定基础速度但PPO控制差速”的方案，因为这会把轮速决策重新交给策略。
也不采用保留16维随机动作、执行时丢弃4维的伪12维方案，以免PPO熵/概率包含无效动作。

## 2. 当前实现与必须纠正的表述

当前16维动作按每腿ABAD/HIP/KNEE/FOOT交错排列，腿位置与轮速度均由PPO输出。
运行env_cfg的前进命令为0.18–0.45m/s随机采样，横向/yaw命令0；不是恒轮速驱动。
当前前进pass是完整、未失败回合的实际世界X位移达到累计目标距离70%，不是有无移动。

现有FK为ABAD绕X、HIP/KNEE绕Y；模型没有独立的车轮yaw转向关节。
腿侧摆不能直接当汽车式转向。固定同速滚动下能否通过腿运动、接触重分配和机身转动
实现有效绕行仍需动态证据；不能承诺必然学会，也不增加虚构转向自由度。
本方案保留用户希望的腿部自主避让目标，而不是把“改变轮子朝向”当已证实能力。

## 3. 动作与速度合同

- 策略、分布、rollout、PPO log-prob/entropy均为12维，按现有命名腿关节顺序映射。
- 腿目标保持现有标称姿态、1.50rad动作尺度和关节限位，不增加IK、swing或动作接管。
- 固定驱动为每个控制步写入四轮前进角速度目标，与策略输出/障碍类别/抬落状态无关。
  抬起的轮子同样保持转动，不按接触状态切零或改速，不用差速避障。
- 用户确认首轮固定轮面目标速度0.30m/s。
  角速度采用配置名义半径M1_WHEEL_RADIUS_M=0.095958m换算，约3.126rad/s；
  必须按资产轮轴符号核实四轮对应同一机身前向，不能盲目相同数值符号。
- 前进命令同步设为恒定0.30m/s，横向/yaw命令保持0，禁止命令随机重采样改变目标速度。
  这是驱动目标，不是强制机身位移或保证实测轮速；保留现有PD/力矩限制和物理接触。
- 轮子受阻仍可能停转/打滑，机身仍可能前进不足；不写root位置/速度、不施加额外推进力。
- 允许实际机身速度偏差，速度误差只诊断，不新增精确速度验收或晋级门槛；
  原70%累计前进距离是任务完成度，不是逐帧精确跟速，保留以防原地刷奖励。

## 4. 观测、奖励和模型兼容

保留轮速实测观测。为了最小化旧300迁移，保持现有观测总长度和16槽执行动作历史：
12槽填实际腿命令，4槽填固定轮驱动在旧尺度下的归一化值；该历史不是策略16维输出。
训练缓存、KL和std只能含12腿维。重置历史采用显式初态，首步实际执行后与执行值一致。
动作差分等直接访问action_manager的项须逐项审核维度：不得把12维按16维索引；
保持原奖励聚合尺度，不因维数变化隐式放大，固定轮命令的差分不生成学习动作惩罚。
轮功率、轮滑动和真实碰撞惩罚仍从物理状态计算，不因不由PPO输出而删除。

继续以此前用户指定的18-49-19/model300作为迁移来源，不删除原PT，不复用已删失败PT。
转换是新动作合同的显式初始化，不能叫原16维精确续训：
复制编码器、critic和共享形状参数；按命名腿列选actor末层行、bias及12腿std；
optimizer对应末层/std的矩状态同样选行，其他状态原样保留，参数身份逐项核对。
不随机重置std、不静默丢弃optimizer；不支持的状态形状必须失败并报告。
保存新动作合同版本、轮速/映射、来源SHA和转换清单；普通load拒绝16/12维错配。
转换测试比较同一旧观测输入下新actor输出与旧actor腿列、std/optimizer切片的一致性。
该相等性不代表新固定轮驱动与旧策略的整机行为相同。

## 5. 小障碍跨越与大障碍避让

stage1–3保留8目标+70填充、同XY/尺寸、仅高度3/6/10cm；不把小目标绕行当成功。
自主起抬/落腿时机保留，不规定水平起抬点，不恢复竖直2cm成功前提。
真实三轮支撑、每次overlap轮底>=障碍顶+3cm、无碰撞、远侧承重落轮和5帧恢复不放宽。
高水位预算、持久正奖励屏蔽及小障碍轮轨义务保持。

大障碍在既有mixed阶段/独立评估场景检查；不能用只有小障碍的stage1声称学会避大障碍。
大障碍不得建立“小障碍必跨”的持久义务；碰撞/越界仍失败。
本次不改地形或奖励权重，不增加路线teacher；审计侧向/yaw跟踪及轮轨成本是否与大障碍
绕行冲突。若存在必须修改的新奖励合同，记录具体反例后单独说明，不偷偷放宽小障碍约束。
避让验收要求实测绕过真实大障碍、整机无碰撞、不越边界并继续前进；有转角不等于绕过。
