# M1 在线 MPC Teacher 跨越与避障训练设计

## 目标

使用现有 checkpoint `/home/hexinkun/m1_rl/logs/rsl_rl/m1_cross_large_complex_ame/2026-09-22_13-04-27/84e52dd/model_16900.pt` 继续训练，使 M1 在接近障碍物前主动抬腿跨越可跨越的小障碍物；对超过能力范围的大障碍物提前改变横向路径绕行，并避免碰撞。

## 训练架构

MPC 作为在线 teacher。每个仿真步根据语义高度图、障碍物尺寸、相对距离和机器人状态判断跨越或绕行，并生成短时参考轨迹/足端目标。PPO 使用当前策略动作与 MPC teacher 动作的混合动作：

`a = teacher_ratio * a_mpc + (1 - teacher_ratio) * a_ppo`

teacher_ratio 随训练进度退火：

- 初期 1.0，确保学习正确的提前抬腿和绕行；
- 中期逐步降至 0.5、0.2、0.05；
- 后期降至 0.0，策略完全自主执行。

## 轨迹类型

训练数据和在线 teacher 覆盖完整过程，而不是只覆盖跨越瞬间：

1. 平地接近与正常行走；
2. 小障碍物接近、提前抬腿、越过、落腿和恢复步态；
3. 大障碍物识别、横向绕行、通过和恢复；
4. 左右两侧绕行；
5. 不同障碍物高度、宽度、间距和横向偏移；
6. 失败恢复与无碰撞安全样本。

小障碍物使用 3–6 cm，高障碍物设置为明显超过可跨越范围，避免 teacher 将大障碍物错误地规划为跨越。

## PPO 学习信号

在现有奖励上增加或校准：

- 足端提前抬升和足端 clearance；
- 跨越阶段的足端时序；
- 障碍物顶部和前后安全距离；
- 几何碰撞强惩罚；
- 大障碍物绕行进度；
- 越过障碍物后的恢复稳定性；
- 保持正常前进速度和姿态。

碰撞不作为唯一终止条件；严重碰撞、翻倒、非有限状态和超时仍终止 episode。

## 续训与安全验证

从现有 checkpoint 继续训练，保留网络结构和观测维度。训练阶段逐步加入：

- 障碍物高度和距离随机化；
- 摩擦、质量、动作延迟和传感器噪声随机化；
- 无障碍和障碍混合场景；
- teacher_ratio=0 的独立评估。

真机前必须满足：teacher_ratio=0 时小障碍物无碰撞跨越，大障碍物保持安全绕行，且平地行走性能不明显下降。

## 验证指标

记录：

- 小障碍物跨越成功率；
- 大障碍物绕行成功率；
- 碰撞率；
- 首次抬腿与障碍物的距离；
- 越过障碍物后的落腿时间；
- 最小足端 clearance；
- teacher_ratio=0 时的自主成功率。
