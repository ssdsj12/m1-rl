## 1. 目标和范围

纠正实测机身位置误差，而不是只据误差冻结插值。先通过原空地支撑准备，再逐级验证抬落和10cm跨越，不保证本候选必能成功。已有数据支持承重静差假说，未证明唯一力学原因。

仅修改 Teacher 的目标生成、事务状态和隔离探针证据。保留原16维动作接口（12腿位置、4轮速度），原资产、质量、重力、PD、rootZ .62m、物理关节限位、课程与20s时限；不使用力矩前馈、动力学优化、MPC、WBC、AMP、外部扶持或直接写状态。

真实三轮支撑、COM余量10mm、跟踪位置10mm、原姿态/速度/载荷条件、无碰撞穿透及远侧5帧恢复保持。碰撞每控制步2分/累计20不重复终止费用保持。学生观测、奖励、std不变，BC/PPO尚不启动；学生阶段完全移除本反馈、Teacher与IK。

## 2. 单一外层反馈，分配到现有执行通道

原生失败主要是位置/COM未达、姿态和载荷仍合格。本候选只增加**位置反馈**，不再增加姿态增益、关节积分器或重力模型。原捕获航向控制保留。

以捕获yaw定义heading旋转H（heading到world）。物理参考位置为p_ref，实测为p_meas，位置误差 `e=H.T@(p_ref-p_meas)`。使用当前实测，不由参考年龄、预测COM或上一回合误差代替。

- **纵向X**：通过现有轮速度目标加入一个四轮相同的有界纠偏量，处理共同滚动/漂移；不让同一X误差再进入腿部补偿。BALANCE/LIFT/RESTORE原名义轮速0，允许小幅正负纠偏；PASS在原名义轮速和捕获航向纠偏上叠加该共同量。APPROACH/尚未捕获时不启用。
- **侧向Y和高度Z**：在名义机身位姿上增加小幅虚拟位移，再用现有四腿受约束IK生成腿位置命令；不尝试用轮速制造侧向速度。虚拟参考不是实际位姿，也不是新的课程目标。
- 姿态参考、四轮世界锚点、目标轮顺序、LIFT轮世界目标、PASS共同XY锚点运输规则不变。姿态仍通过原参考和IK控制，不新增姿态积分。

初版参数固定如下，均是待原生验证的候选值，不是“已调好”的参数：

| 量 | 固定值 |
|---|---|
| X轮速比例系数 | 1.0 s^-1 |
| X轮速积分系数 | .2 s^-2 |
| X积分输出绝对值上限 | .02 m/s |
| 共同轮面纠偏速度绝对值上限 | .04 m/s |
| 轮面纠偏速度变化率 | .10 m/s²（20ms最多.002m/s） |
| Y/Z虚拟位置比例系数 | .5 |
| Y/Z虚拟位置积分系数 | .5 s^-1 |
| Y/Z积分输出绝对值上限 | 各.01m |
| Y/Z总虚拟位移绝对值上限 | 各.02m |
| Y/Z虚拟位移变化率 | 各.02m/s（20ms最多.0004m） |

总轮速仍须满足原动作/电机速度上限；若名义速度加纠偏超界，缩小纠偏，不修改名义动作或电机上限。腿最终目标相对上一实际apply目标仍≤2.5rad/s，原关节限位、膝分支、abs(knee)≥.10保持。

## 3. 三类参考必须分开

1. **物理名义参考R_phys**：原候选搜索/插值接受的root及四轮world参考；前后±4cm、侧向±6cm、降低≤8cm等原包络不变。只有实际跟踪、载荷、COM等原门槛通过才推进阶段和年龄。
2. **虚拟执行参考R_cmd**：`p_cmd=p_ref+H@[0,u_y,u_z]`，姿态不变，四轮world目标仍为R_phys的目标。仅用于构造IK执行目标；其Y/Z最多比物理参考多2cm，可能超过物理参考包络，但不允许将此偏置写回R_phys或作为新的成功位置。
3. **实测R_meas/q_meas**：来自真实仿真；准备、LIFT和恢复判断只对R_phys及原实际事件检查，绝不要求机器人“跟到虚拟超调位置”才成功。

IK的2mm残差分别记录为名义几何解残差和虚拟执行解残差。不能拿R_cmd的可达性证明实际机器人或R_phys已达到。拒绝通过事后clip关节来伪称IK解有效。

若实际root偏离原捕获包络，不能移动锚点或扩大名义包络吸收它；记录偏差，使用原实际安全检查与20s上限。虚拟偏置本身不改变环境termination，也不构成机身实际允许越界的豁免。

## 4. 更新、回溯与防积分累积

每个env/episode保存：R_phys、上一已接受R_cmd、Y/Z偏置、X轮速纠偏、三路积分输出、上次控制帧和目标身份。测量→名义参考提案→反馈提案→名义/执行IK及真实decoder/连续性检查→实际apply核对，事务通过后才提交。

冻结R_phys进度不冻结纠偏；TRACKING时仍可根据实测误差更新上述输出。IK/测量/安全无效时则不更新任何积分或参考，只允许原已认证的连续hold；无合法hold仍在物理步前整批abort。

反馈的有限幅度和变化率限制先在任务空间形成提案，不是关节clip。尝试至多8档beta=1,1/2,…,1/128，同时回溯名义参考增量（允许推进时）和反馈输出增量；每档检查名义及虚拟四腿IK的残差、限位与分支。仅最终虚拟执行解经真实decoder后与上一apply检查连续性；名义解不是实际命令，不要求它相对已补偿的上一命令满足slew。每个IK仍最多32次内部迭代/2mm残差。

积分候选 `I_new=I_old+Ki*e*dt`。仅在当前测量有限、原三支撑载荷条件满足、无碰撞/失支撑/锁定、该步最终全部成功且无幅度/变化率/轮速总限幅或回溯时接受积分更新。其余情况保持I_old，使用I_old重新构造有界反馈，禁止提交曾被拒绝的积累。饱和时允许使该轴绝对积分减小的增量，仍须最终事务通过；不补发历史积分。

防积分重算至多一次：第一遍尝试积分候选；若需要回退积分，第二遍固定为旧积分（仅保留已判定可减小饱和轴绝对积分的分量），重新做限幅及8档事务检查，不再递归重算。第二遍无合法解则使用原认证hold或abort。总上限为2遍×8档×2个四腿IK，每个单腿求解最多32次；重算前任何提案不得apply或提交。积分分量也必须满足表中的绝对上限。

捕获前积分为0；准备/抬轮/PASS/恢复之间连续保留。回到APPROACH后积分清零，轮速纠偏按变化率回零；腿目标通过已有真实目标连续性回溯过渡，不突然去掉命令偏置。新episode只清对应行；新捕获要求上一补偿输出已回零，否则保持原正常动作过渡、不开始新准备。重复帧不更新，缺帧不按缺失时长积累，只用一次真实控制dt；终止前保存旧快照。

APPROACH退出补偿不再计算PI：Y/Z偏置按各.02m/s向0衰减，并用上次接受参考与原APPROACH参考之间的既有连续性回溯构造执行命令；X同样只衰减，不新增误差纠偏。输出未归零前保留必要旧参考作过渡，不把它当成新捕获。原生证据必须覆盖此退出段，不能仅验证开启段。

COM不达10mm不能关闭位置反馈，否则会重新形成准备僵局；但预测COM不得作为通过信号。load只用于安全准入/拒绝，不把不完整contact force当作精确力矩前馈。

## 5. 模块、测量和证据

新增纯张量`m1_teacher_feedback.py`负责误差、PI提案、限幅/变化率和anti-windup，不操作仿真、状态机或奖励。Teacher负责逐行事务与阶段；pose/IK模块负责名义/虚拟几何检查；adapter仅读取真实输入；probe记录request/process/apply/physics链。

新schema/fingerprint保存R_phys/R_cmd/R_meas、heading误差、积分更新前/候选/提交值、偏置、X纠偏和名义/最终四轮速度、限幅原因、回溯档位、两组IK残差、旧/新实际apply目标及phase进度。旧日志不补造这些字段。

探针另外按真实名称保存瞬时leg/wheel joint_vel、腿computed_effort和applied_effort（标记API来源），用于区分PD比例项、阻尼和实际限幅；轮Implicit的effort若只能估算，明确标记为估计，不冒充PhysX真值。数据不进入学生观测，不从有限差分伪造瞬时量；缺少必填腿证据明确拒绝本轮诊断验收。

所有局部试验和失败/abort均不能作合格BC示范。此前abort审计完整性Minor继续单列；不得借本规格声称已解决或把它们收入成功数据。

## 6. 验证及停止边界

- CPU先构造旧实现失败的误差反馈反例：同一prepared/TRACKING，改变真实机身位置后纠偏提案的方向/幅度响应；变化率或幅度饱和可能令首步命令相同，要分别检查未限幅提案、限幅原因和后续有界命令，不能硬要求所有误差大小都产生不同首步动作。
- 覆盖非零yaw/full quaternion坐标、X不重复进入腿通道、Y/Z不影响共同轮速、正负轮速单位/命名顺序、零误差含残余积分、防windup、拒绝/回溯/重复帧/缺帧/单行reset、补偿退出连续性、原no-executable abort。
- 检查R_phys冻结而补偿能动、虚拟2mm不能认证实际ready、测量偏差未消失不得推进；补偿激活前后真实process/apply一致，不能换一组目标冒充另一组残差。
- 原v2反例仍作为旧证据保留。本候选使用原重设计剩余的一次单机制原生修订，不重开无限参数试验预算。先CPU及独立审查，再GPU空闲且串行的原生合同。
- 按空地准备→四轮各自抬落→首10cm障碍→衔接→完整课程顺序；准备局部探针在首次ready后额外记录5个连续输入/输出ready帧，期间教师仍仅准备，任何一帧不满足则重新计数。此为局部保持诊断，**不修改生产成功规则、20s上限或正式教师阶段门槛**。
- 首关键失败停止，不改增益重跑、不改PD/时限/阈值。保存真实关节速度/effort与补偿饱和链，汇总新的决策；不自动转第二种力矩方案。
- 全部局部通过后才正式跑平地/10cm各5seed×20，原≥95/100不变。同初态相关并行行数不是独立统计成功率；保留seed/attempt、失败和not_run分母。
- 本规格到教师A验证结束；BC、撤除与独立PPO按父计划另行实施，不能边验证边训练。

## 7. 范围选择与风险

用户选择第一种，而非力矩前馈：依赖现有16维动作，无新物理力矩层。纵向采用微小轮速纠偏是此方案的具体细化，已随本书面规格确认；仅靠改变腿形不能保证恢复共同纵向漂移。Y/Z虚拟偏置可能饱和、振荡或无助于承重，轮微动也可能提前接近障碍；都必须在原碰撞和实际支撑规则下暴露，不保证跨越。

本候选不增加关节误差积分和姿态反馈，避免一次叠加多个未经定位的机制。若实际根因不是本反馈能纠正的误差，按预算停止，不继续扩大控制范围。
