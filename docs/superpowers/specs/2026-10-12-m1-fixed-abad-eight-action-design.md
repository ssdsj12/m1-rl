# 固定ABAD目标、8维HIP/KNEE PPO：model200显式迁移

## 状态与用户意图

架构级设计，待书面审阅；尚未实施、部署或启动训练。最新用户选择覆盖此前“从零”：从空地表现较好的model200继续，保留已有能力，限制策略侧摆自由度，让PPO自行学习收腿或摆腿越障。

基线代码83aa11d已发布到10-12。固定目标不是物理锁死，不保证绝对直行；ABAD受力偏转、左右承重不均、滑移仍能导致偏航。横向平衡与大障碍绕行能力会受限，不能承诺越障成功。

## 已选方案与排除项

选择固定四个ABAD位置目标0rad、保留原位置PD；PPO只输出8个HIP/KNEE动作。对比方案为物理锁死ABAD，用户未选，禁止改USD关节类型/限位或提高刚度来冒充固定目标。

不加机身yaw/世界Y约束、不设前进速度强制器、不增加差速/停轮/IK/teacher/模仿/轨迹/WBC。奖励、成功标准、地形与参考物理参数本轮保持原样。8维动作不是保留12维网络再屏蔽4个输出。

## 动作与观测接口

- 策略动作顺序：FBL_HIP、FBL_KNEE、FAR_HIP、FAR_KNEE、RBL_HIP、RBL_KNEE、RAR_HIP、RAR_KNEE（实际名称均带_JOINT后缀）。actor输出、采样分布、std、PPO storage/log_prob/entropy都必须为8维。
- HIP/KNEE目标仍是参考角加1.50rad乘策略动作，并按现有关节限位裁剪。前HIP+.30/KNEE-.60，后相反。
- 每个物理子步下发四ABAD位置目标0rad和四轮0.30m/s目标；PD、力矩和速度限制不变。ABAD实测角仍保留在本体观测内，不能写回/覆盖真实状态。
- 动作历史继续采用既有16列执行命令表示，按名称展开8维动作，ABAD归一化命令为0，轮列为原固定轮命令。12腿历史访问器提供展开后的12列，而非把8列假装成12列。初始和reset历史清理沿用现有语义，活跃步记录实际下发命令。
- 现有85维policy state、88维critic state及AME地图结构保持；不移除ABAD实测反馈，不向actor新增terrain registry。核对全部消费动作的奖励/日志/观察器，不能误把ABAD固定0解读为实际角0。
- 新模式必须显式选择；保留旧12/16维模式的原行为，评估读取模型合同选择正确模式。入口和保存/加载不能仅凭“固定轮速”就假定12维。

## model200来源与迁移合同

- 使用已经批准的stall-slip初始化model_200_stall_slip.pt，SHA256为792fbd76684db07fac1f9bfa0041ce35e8a3fc7c72497ec6c62d75d6e0d527b7。它的模型张量已与reference run2026-10-12_12-26-20/bb57e7d/model_200.pt逐项相同，后者SHA为098616326b726de0494f2a6376766a67073a01b2d00751ce8ec98f027b12a67f。
- 原始及12维转换PT都不覆盖，另存8维初始化PT。只按名称截取actor最终输出层的HIP/KNEE行、对应bias、8个std及这些参数对应Adam矩；其他actor/critic/编码器/BatchNorm状态逐张量保持。Adam step与param_groups保持。不手调std、不重建优化器状态、不从500续训。
- 明确记录来源SHA、旧/新动作合同、选择索引及固定ABAD目标；新动作合同包含mode/version、8策略关节名、4固定ABAD名与角、轮速、16列历史顺序。训练合同新增固定ABAD语义版本；不把动作转换标为奖励改动。
- 普通加载拒绝未经转换的12/16维PT、映射/固定角/轮速不一致、非有限值、缺失或形状错误Adam、无课程状态；不允许静默截断或宽松load绕过检查。
- 保留iter200/next201、stage0/streak1及原课程窗口，从201运行9799次至exclusive10000，save100、2048env、GPU0、keep_std与加载优化器。200不是stage0结束的249PT，不能跳过剩余stage0。
- 等输入前向下，转换后8个actor均值应与源策略对应8行数值一致；这只证明权重迁移，闭环行为会因ABAD固定和执行历史变化而不同，不称精确恢复。

## 验收与部署边界

1. CPU反例先行：8维分布与动作映射、固定ABAD及轮目标、16列历史/reset、旧模式回归；12/16错装8、错顺序/速度/固定角/NaN必须拒绝。迁移逐张量验证权重、Adam、std、课程和来源，保存后再次加载一致。
2. 先在隔离候选原生验证四ABAD目标每次保持0（实测角允许PD误差）、8维随机策略和固定轮执行、所有课程stage/reset/terminal、奖励有限和日志维度。旧PT全保留，不允许训练旁并发native。
3. 空地复测用sim.current_time验证100控制步实际2秒；消除演示入口额外simulation_app.update物理推进，作为同一评估链必要修正并单独回归。比较源200与转换200的前进/偏航/目标变化/各轮Fz/ABAD实际误差；不以强行固定机身方式做绿。
4. 行为对照不要求8维与12维闭环完全相同；若出现新的明显失稳，先记录并定位，不自动加PD、放宽标准或启动长训。随机探针失稳不直接认定不可学习。静态折腿夹具仍不是开训门槛。
5. 候选检查通过、确认无训练/probe并发后，备份并校验部署文件，独立保存8维初始化，启动新run。核实cmdline/cwd/env_cfg实际8动作/2048/.30/固定ABAD/来源/迭代；等待实际优化更新及首个新PT的CPU审计。所有probe退出后才能开训。
6. 新run通过基本启动核验后将TensorBoard指向它，沿用既有显示/网络配置，不重启旧watcher。不把进程启动当成学习成功。每次原生检查和部署留下日志/哈希与可恢复源。

零额外净空、碰撞重置、三轮真实支撑、实际经过、远侧5帧恢复，以及stall/slip和其他既有奖励不变。必须真实完整事件/视频才可声称掌握跨越。根高.62、物理参数、地形8目标+70填充/3、6、10cm不变。
