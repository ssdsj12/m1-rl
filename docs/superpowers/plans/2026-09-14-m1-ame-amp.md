# M1 AME / AME-AMP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `parallelism-amp` 基线上增加可训练的 M1 AME 与 M1 AME-AMP，保持 16 维 RL action、12 维腿部 planner/AMP joint contract，并完成真实 Isaac Lab smoke。

**Architecture:** 保留 `ame_baseline`、Runner、Policy、PPO/GAE、AMP discriminator/replay/checkpoint 的现有实现，仅新增 M1 环境配置、命名 selector 与训练入口。M1 Parallelism backend 来自 GitHub `m1@844c72d`，reference manager 通过 `robot_name` 选择 backend；资产 16 关节通过显式名字映射为 planner 12 关节，四个轮子仅由策略 action head 控制。

**Tech Stack:** Python 3.10、PyTorch 2.7、Isaac Sim 4.5、Isaac Lab 2.2.1、Gymnasium、rsl_rl、pytest。
